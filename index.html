§02 Proyectos

Plataforma de monitoreo
para subestaciones eléctricas.

En Movi Software desarrollo una plataforma web para el monitoreo y control de sistemas eléctricos en subestaciones. Estos son dos componentes representativos del trabajo: uno en la capa de visualización y otro en el procesamiento de datos.

Reto 01

Interfaz de monitoreo y visualización de equipos.

  • JavaScript
  • HTML / CSS
  • API REST
  • UX

Desarrollo de una interfaz web para visualizar el estado de equipos electrónicos distribuidos en múltiples subestaciones, consumiendo datos en tiempo real desde servicios .NET vía APIs REST. Participé en la definición de mockups y en el diseño de la información en pantalla, decidiendo qué variables mostrar, cómo agruparlas y qué jerarquía visual usar para que el operador pueda diagnosticar rápidamente.

Reto técnico

Renderizar múltiples variables y estados en una misma vista sin saturar al usuario, manteniendo el rendimiento del frontend ante actualizaciones frecuentes.

Resultado

Vista funcional que permite analizar datos, validar el estado de los equipos y comprender el comportamiento del sistema en distintos escenarios operativos.

Reto 02

Procesamiento de datos de simulación y operación real.

  • .NET (C#)
  • Python
  • SQL
  • API REST

Implementación de la lógica de procesamiento que toma datos crudos —tanto de simulaciones como de equipos en operación— y los transforma en información estructurada para análisis. Incluye consultas SQL para extracción y agregación, servicios backend para el cálculo, y endpoints REST que entregan los resultados a la capa de visualización.

Reto técnico

Estandarizar el flujo de procesamiento para que sirviera tanto a datos de simulación como a datos reales, manteniendo trazabilidad en el análisis de eventos y fallas del sistema.

Resultado

Herramientas que entregan datos procesados de forma consistente al frontend, soportando análisis comparativos entre escenarios simulados y mediciones reales.
