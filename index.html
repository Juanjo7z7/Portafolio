§03 Proyectos

APOLO — plataforma de monitoreo
para subestaciones eléctricas.

Producto desarrollado en Movi Software para Celsia. Centraliza el monitoreo de cientos de equipos distribuidos por regiones (Valle, Tolima, Caribe), permite revisar eventos de falla y analizar comtrades. Estas son dos vistas representativas del trabajo: la capa de visualización y la de procesamiento.

Reto 01

Interfaz de monitoreo y visualización de equipos.

  • JavaScript
  • HTML / CSS
  • API REST
  • UX

Desarrollo de una interfaz web para visualizar el estado de equipos electrónicos distribuidos en múltiples subestaciones, consumiendo datos en tiempo real desde servicios .NET vía APIs REST. Participé en la definición de mockups y en el diseño de la información en pantalla, decidiendo qué variables mostrar, cómo agruparlas y qué jerarquía visual usar para que el operador pueda diagnosticar rápidamente.

Reto técnico

Renderizar cientos de equipos con sus estados, archivos y accesos rápidos sin saturar al operador ni perder rendimiento ante actualizaciones frecuentes.

Resultado

Vista funcional que permite filtrar por zona, validar el estado en tiempo real, descargar archivos del equipo y entrar al histórico con un click.

Reto 02

Procesamiento de datos de simulación y operación real.

  • .NET (C#)
  • Python
  • SQL
  • API REST

Implementación de la lógica de procesamiento que toma datos crudos —tanto de simulaciones como de equipos en operación— y los transforma en información estructurada para análisis. Incluye consultas SQL para extracción y agregación, servicios backend para el cálculo, y endpoints REST que entregan los resultados a la capa de visualización.

Reto técnico

Procesar archivos comtrade (datos crudos de los relés) y generar análisis comparables entre simulación y operación real, manteniendo trazabilidad y reproducibilidad.

Resultado

Más de 80 gráficas generadas por evento (impedancia, componentes simétricas, RMS, ángulo y magnitud) que el equipo de protecciones usa para diagnosticar fallas en campo.
